A program that writes the plan an AI agent would follow to turn $100, a computer with internet access and 30 days into the most money: one product — a working automation (scraper, cleanup, or bot) for $249 — sold only to people who already asked for it, demo running on their data. The full $100 is accounted for, the funnel rates are discounted, and 1 of 500 answers paying covers the spend.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
